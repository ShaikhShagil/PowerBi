# PowerBi
PowerBi Project for Data Analytics


🗂️ Data Model Description
👨‍🎓 Student Profile Table

Stores core student information and academic details.
Includes attributes like CGPA, department, and year of study, which help evaluate eligibility for job roles.

🧠 Skills Master Table

Acts as a centralized repository of all skills (technical, soft, domain).
Ensures standardization of skill names across the system.

🛠️ Student Skills Table

Maps students to their skills along with proficiency level (1–5) and certification status.
Used to assess individual capability and readiness.

💼 Job Requirements Table

Contains job-level details such as company, role, minimum CGPA, and domain.
Helps match students with suitable opportunities.

🎯 Role-Skill Mapping Table

Defines the required skill proficiency for each job role.
This is the core table for performing skill gap analysis.

📊 Placement Status Table

Tracks the recruitment lifecycle including:

Application status
Salary offered
Recruiter feedback

Used to measure placement success and performance trends.

🔍 Key Features of the Dashboard
📊 Student Performance Analysis (CGPA, department-wise insights)
🧠 Skill Gap Analysis (required vs actual skills)
💼 Job Role Matching (eligibility and fitment)
📉 Placement Funnel Tracking (Applied → Interview → Placed)
💰 Salary Insights (average package, company-wise offers)
🌍 Domain & Industry Trends
🎯 Business Use Cases
Identify students who are placement-ready
Recommend skills to improve for specific roles
Help placement cells target training programs
Assist recruiters in shortlisting candidates efficiently
